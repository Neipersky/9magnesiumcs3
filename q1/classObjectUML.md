# SG4 - Understanding Classes and Objects
## Class Name
Estinien
## Class Description
Estinien is a Dragoon from Final Fantasy XIV: Heavensward. He is known as the Azure Dragoon and is one of the important characters in the story. He uses a lance and has special attacks that are based on the Dragoon fighting style.
## Properties
| Property | Data Type | Description |
|---|---|---|
| name | String | Stores Estiniens name. |
| level | Integer | Stores Estiniens current level.|
| health | Integer | Stores how much health Estinien has. |
| isAzureDragoon | Boolean | Shows whether Estinien is the Azure Dragoon. |
## Methods
| Method | Description |
|---|---|| | |

| TrueThrust() | Estinien uses his lance to perform a basic thrusting attack. |
| DragonDive() | Estinien dives toward the enemy from the air and deals a powerful attack. |

## Design Explanation
### Why did you choose this class?
I chose Estinien because he is an important character in Final Fantasy XIV: Heavensward and is known as the Azure Dragoon. His Dragoon abilities also make him a good example for a class and its methods.
### Which property is the most important? Why?
I think health is the most important property because it shows how much damage Estinien can take before he is defeated.
### Which method is the most useful? Why?
DragonDive() is the most useful method for me because it is a strong attack that fits Estiniens Dragoon fighting style.
